# GEO 실행형 분석 대시보드

GA4 유입 데이터를 브라우저에서 직접 분석해 **GEO(Generative Engine Optimization) 개선 액션**으로 연결하는 실행형 대시보드입니다. 서버 없이 단일 HTML 파일로 동작하며, 데이터는 브라우저 밖으로 전송되지 않습니다.

## 사용 방법

1. 대시보드를 브라우저에서 엽니다 (GitHub Pages 또는 `index.html` 직접 열기).
2. GA4에서 추출한 탭별 CSV 파일을 업로드합니다.
3. **분석 시작**을 누르면 브라우저 안에서 즉시 분석됩니다.

## 입력 데이터 (GA4 CSV 4종)

| 탭 | 역할 | 내용 |
|---|---|---|
| ① GEO_AI_콘텐츠 | AI 콘텐츠 | AI 검색엔진(Bing, Perplexity 등) 유입 세션·페이지 |
| ② GEO_전체채널 | 전체 채널 | 채널 그룹별 전체 유입 비교 기준선 |
| ③ GEO_지역 | 지역 분포 | 국가·도시별 유입 분포 |
| ④ GEO_콘텐츠분류 | 콘텐츠 그룹 | 콘텐츠 그룹·주제별 조회수 |

각 탭의 GA4 추출 조건은 대시보드 하단 **"GA4 추출 가이드"** 섹션에 항목별 매핑으로 정리되어 있습니다.

## 주요 기능

- **진단 통합**: 입력 데이터 간 정합성 점검, 이번 데이터의 원인 해석, 추천 GEO 액션 자동 제시
- **토픽 분석**: 토픽 점유율, 상위 집중도, 이탈률 기준 고관여 콘텐츠 TOP 10
- **실행 연결**: TOP 10 기사를 콘텐츠 개선 작업으로 연결하는 체크리스트
- **GEO 방법론**: AI가 인용할 가치를 만드는 9가지 방법(인용 출처·인용문·통계 추가, 유창성 개선, 쉬운 언어, 권위적 어조, 기술 용어 강화, 희소 단어 활용, 키워드 스터핑 주의)과 공개 벤치마크 근거
- **측정 지표**: PAWC(Position-Adjusted Word Count), Impression 기반 인용 품질 지표 — GA4 유입과 AI 인용 품질을 구분해 측정

## 기술 구성

- 단일 HTML 파일 (별도 빌드·서버 불필요)
- [Chart.js](https://www.chartjs.org/) 4.5 · [Grid.js](https://gridjs.io/) 5.0 (CDN 로드)
- CSV 파싱·분석 전 과정 클라이언트 사이드 처리 — 업로드한 데이터는 외부로 전송되지 않음
